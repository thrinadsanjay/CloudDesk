# OS logos

Drop official logo files here, or in `images/` for extra artwork. The filename (without extension) should match the OS id used in Admin → Settings. Use **Admin → Settings → Login graphic** to pick one file from `images/` for the login page.

Suggested names:

- `debian.png`
- `ubuntu.png`
- `redhat.png`
- `rocky.png`
- `windows.png`

Accepted types: `.png` `.svg` `.webp` `.jpg` `.jpeg` `.gif`

After copying files, open **Admin → Settings** to confirm or create the mapping, then pick that OS in the desktop dropdown.
